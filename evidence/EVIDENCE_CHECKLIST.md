# Evidence Checklist

Capture genuine screenshots from your Linux lab:

- `01-navigation-files.png` — folder structure and file operations.
- `02-readme-editing.png` — name, Kernel/FHS/Shell notes, and viewing/search commands.
- `03-permissions-ownership.png` — `ls -l secure.txt` showing mode and owner.
- `04-archive-restore.png` — archive creation and restored file list.
- `05-process-management.png` — process inspection and termination verification.
- `06-networking.png` — IP, hostname, listening ports, and hosts-entry verification.
- `07-searching.png` — `find` and `grep` results.
- `08-package-management.png` — `tree --version` before removal and `packages.txt`.
- `09-hello-script.png` — script and its output.
- `10-system-monitoring.png` — disk, memory, logs, uptime, users, and CPU details.

Only include screenshots you actually captured. Do not include passwords, tokens, or unrelated personal information.
