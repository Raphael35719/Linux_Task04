# Workflow — Task 04

1. Prepare an authorized Kali/Linux lab.
2. Activity 1: create `linux_lab`, files and subdirectories; copy, move, delete, and display structure.
3. Activity 2: edit `readme.txt`; use `head`, `tail`, `wc`, and `grep`.
4. Activity 3: set `secure.txt` to `640`, then `777` as requested; optionally create `student2` and change ownership.
5. Activity 4: create three text files, archive, gzip, extract, and verify.
6. Activity 5: start and inspect `sleep 300`, foreground and stop it, verify termination, and use `top`.
7. Activity 6: inspect IP, hostname, and ports; test connectivity; update `/etc/hosts`; verify.
8. Activity 7: search for files and text, find recently modified files, and count `.txt` files.
9. Activity 8: update apt, install and verify `tree`, remove it, and save installed packages.
10. Activity 9: create, make executable, and run `hello.sh`.
11. Activity 10: inspect disk, memory, logs, uptime, users, and CPU.
12. Capture actual evidence, save useful outputs, review the repository, and push with Git Bash.
