# Linux Task 04 — Practical Test Package

This repository organizes the 10 activities in the supplied Linux Practical Test Package into a task guide, ordered workflow, command reference, evidence checklist, outputs area, and GitHub submission guide.

## Directory map
- `what-to-do/` — task requirements and step-by-step guidance.
- `workflow/` — recommended sequence and progress checklist.
- `commands/` — quick command reference and a sample script.
- `evidence/` — original full PDF and checklist for screenshots you capture.
- `outputs/` — place for genuine command outputs and expected-result checks.
- `submission/` — final review and Git Bash instructions.

Run Linux commands inside your Kali/Linux terminal or VM, not Windows Git Bash. Some activities modify permissions, users, packages, processes, and `/etc/hosts`; use an authorized lab and inspect commands before running them. Only mark tasks complete after verifying your results.
